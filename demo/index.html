What is happening

"Wake" downloads a saved state of a booted machine and restores it into a fresh WebAssembly emulator. The first frame is the exact screen the state was saved with. "Save state" captures the running machine, disk changes included; "Restore saved" brings it back in a new worker.

Emulators

  • v86 (BSD-2-Clause): x86, Windows 98
  • Mini vMac (GPL-2.0): Macintosh Plus
  • Basilisk II, SheepShaver (GPL-2.0): Quadra 650, Power Macintosh G3

Mac cores are Infinite Mac's builds with Asyncify enabled for snapshots; build scripts are in prototype/build/.

Software

Mac OS, its ROMs and Windows 98 belong to Apple and Microsoft. The disk images are the ones used by Infinite Mac and the v86 demo; the Windows image adds the open-source VBMOUSE driver.
